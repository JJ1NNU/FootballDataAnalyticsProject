# 발표 슬라이드 구성안 (개정판): 골키퍼를 올릴 것인가

> 기반 문서: [`project-proposal.md`](./project-proposal.md) · 수치 출처: [`data/derived/summary.json`](../data/derived/summary.json), `data/derived/statsbomb/corners.csv`
> 가정: 기획 발표 10분 안팎, 본문 11장 + 부록. 청중은 축구와 머신러닝을 모두 아는 사람도, 한쪽만 아는 사람도 섞여 있다고 가정합니다.

## 0. 1차안을 다시 검토한 결과

### 0-1. 슬라이드·자료별 필요성 점검

| 1차안 | 판단 | 이유 | 개정안에서 |
|---|---|---|---|
| 1. 표지(사진 배경) | **축소** | 2번의 영상과 같은 장면을 반복해 놀라움이 줄어듦 | 표지는 질문 한 문장. 사진은 쓰지 않음 |
| 2. 영상 2개 동시 재생 | **수정** | 두 영상을 동시에 틀면 소리·시선이 분산됨 | 하나씩 순서대로(성공 → 실패) |
| 3. 연구 질문 4개 | **축소** | 시작부터 질문 4개를 나열하면 무겁게 느껴짐 | 핵심 질문 하나("언제 올려야 하나")만. 나머지는 말로 |
| 4. 선행연구 타임라인 | **축소** | 수업 청중에게 문헌 목록은 지루함. 핵심은 "하키는 했는데 축구는 안 했다" 한 가지 | 한 문장 + 하키 장면 사진 1장으로 3번에 합침 |
| 5. "60건뿐" 점 그리드 | **유지** | 이 연구의 핵심 난점을 한눈에 보여 주는 유일한 그림 | 유지(숫자를 더 크게) |
| 6. 데이터 소스 로그 스케일 막대 | **삭제** | 로그 스케일은 직관적이지 않고, 소스별 규모 비교는 결론에 기여하지 않음 | 소스 이름·규모는 한 줄 표로. **360 프레임 피치 그림만 유지**(데이터가 실제로 어떻게 생겼는지 보여 주는 가치가 큼) |
| 7. 미니 차트 3개 | **분리·일부 삭제** | 한 장에 차트 3개는 과부하. 게다가 **"공격 인원별 xG" 차트는 인원 간 차이(약 0.003)가 표준오차(0.004~0.008) 안**이라 "효과가 작다"는 메시지를 뒷받침하지 못함 | 실점률 차트만 유지(신뢰구간이 겹치지 않는 확실한 결과). 공격 인원 차트는 **"데이터로는 구분이 안 된다 → 모델이 필요하다"** 는 정직한 메시지로 바꿔 방법 슬라이드에서 사용. 빈 골문 득점/xG 차트는 부록으로 |
| 8. 분해 다이어그램 + 9. 아키텍처 | **통합** | 두 장이 같은 내용(분해된 하위 문제 = 모델 블록)을 반복 | 한 장에서 단계적 애니메이션으로 쌓아 올림 |
| 10. 신뢰구간 겹침 "가상" 그림 + 논문 카드 | **삭제** | 가상 데이터 그림은 실제 결과로 오해받을 위험. 논문 카드는 장식에 가까움 | 검증 원칙은 아키텍처 장에서 말로. 참고문헌은 부록 |
| 11. 권장 지도 히트맵 목업 | **수정** | 색이 칠해진 목업은 "이미 결과가 나왔다"는 오해를 줌 | **빈 지도 틀**(축과 범례만) + 한 칸만 손계산 예시로 채움 |
| 12. 한계 아이콘 6개 | **축소** | 6개를 다 들으면 결론이 흐려짐 | 가장 중요한 3개만 슬라이드에, 나머지는 질문 대비 부록 |
| 13. 간트 차트 | **유지(간소화)** | 일정은 평가 항목. 다만 7주를 세세히 읽을 필요는 없음 | 3단계 마일스톤 막대 |
| 14. 청중에게 다시 질문 | **유지·강화** | 처음 질문과 수미상관 | 처음에 받은 투표 결과와 연결 |

### 0-2. 새로 넣은 것
- **"냅킨 계산" 슬라이드**: 지금 가진 실측값으로 저울을 직접 계산해 보면, **"마지막 코너라면 리그에서는 잃을 것이 없다"** 는 결론이 바로 나옵니다. 1골 뒤진 채 끝나면 추가 실점을 해도 승점은 어차피 0점이기 때문입니다. 그래서 진짜 질문은 **"언제부터는 손해인가(시간 경계)"** 로 날카로워집니다. 청중이 스스로 이해하게 만드는 전환점이라 발표 중반의 핵심 장면으로 둡니다.
- **청중 투표**: 시작할 때 "95분 1골 뒤진 코너, 골키퍼를 올린다/안 올린다" 손들기 → 끝에서 같은 질문을 다시 던집니다.
- **용어 번역 원칙**: 전문 용어는 처음 나올 때 한 번만 일상어로 풀고, 슬라이드에는 일상어만 씁니다.

| 전문 용어 | 슬라이드·말에서 쓸 표현 |
|---|---|
| xG(기대득점) | "그 위치에서 슈팅하면 평균 몇 %가 골이 되나" |
| 360 프레임 | "그 순간의 스냅사진 — 화면 속 모든 선수 위치" |
| 그래프 신경망 | "선수와 선수 사이 관계를 통째로 읽는 신경망" |
| 반사실 질의 | "같은 장면에 선수 한 명만 더 넣어 보기" |
| 역방향 귀납 | "종료 휘슬부터 거꾸로 계산하기" |
| 부트스트랩 불확실성 | "데이터를 수천 번 다시 뽑아도 같은 답이 나오는가" |

### 0-3. 발표의 이야기 구조

```
① 질문으로 잡기      ② 아무도 답 못 한 이유      ③ 우리의 아이디어         ④ 손으로 풀어 보기          ⑤ 무엇을 내놓고, 얼마나 믿나     ⑥ 다시 질문
 (투표 + 영상 2개)  →  (60건뿐 / 하키는 했다)  →  (쪼개서 측정 + 데이터)  →  (마지막 코너는 무조건 GO?  →  (권장 지도 / 한계 3개 / 일정)  →  (투표 다시)
   1~2분                1.5분                       3분                       → 그럼 언제부터 손해?) 1.5분     2.5분                               0.5분
```

청중이 매 단계에서 다음 질문을 스스로 떠올리도록 연결합니다: "정말 이득일까?" → "왜 아무도 몰랐지?" → "그럼 어떻게 재?" → "오, 마지막엔 당연히 올려야 하네. 그럼 언제부터?" → "그걸 지도로 만들겠다."

## 1. 슬라이드별 구성

### S1. 표지 + 투표 (40초)
- **그림**: 없음. 검은 배경에 질문 한 문장.
- **글**: "95분, 1골 뒤진 코너킥. 골키퍼를 올리시겠습니까?" 아래 작게 제목·팀명.
- **말**: 청중에게 손을 들게 합니다(올린다/안 올린다). 결과를 대략 기억해 두었다가 마지막에 언급합니다. "감독들은 매주 이 결정을 하는데, 축구에서는 아직 아무도 데이터로 답하지 않았습니다."
- **이유**: 첫 10초에 참여를 끌어내고, 발표 전체의 질문을 각인시킵니다.

### S2. 같은 선택, 정반대 결과 (70초)
- **영상**: 순서대로 재생합니다(각 10~15초).
  1. 알리송 95분 헤더 결승골(리버풀, 2021) — [NBC Sports](https://www.youtube.com/watch?v=CFXkwCtEzDQ)
  2. 조지아 골키퍼 가담 → 90+7분 빈 골문 실점(유로 2024) — [FOX Soccer](https://www.youtube.com/watch?v=f7JinPLrBOg)
  - 현장 인터넷 대비 로컬 클립과 정지 화면 백업. 출처 표기.
- **글**: 각 영상이 끝난 뒤 한 줄씩 떠오르게: "무승부 → 승리 (+2점)", "1골 차 패배 → 2골 차 패배".
- **말**: 상황(점수·시간)만 짧게. "결과만 보면 둘 다 '그럴 수 있지'입니다. 질문은 **평균적으로** 이득이냐, 그리고 **언제** 이득이냐입니다."
- **이유**: 성공을 먼저 보여 줘 기대를 올린 뒤 실패로 긴장을 만듭니다. 동시 재생보다 감정선이 분명합니다.

### S3. 하키는 답했고, 축구는 아직이다 (50초)
- **그림**: 아이스하키에서 골리를 빼고 빈 골문으로 경기하는 장면 사진 1장(출처 표기).
- **글**: "하키: 골리 빼기 연구 → 결론 '감독들은 너무 늦게, 너무 드물게 뺀다'" / "축구: 블로그 분석 1편, 그마저 숫자는 하키에서 빌려 와 가정".
- **말**: 하키 연구(Beaudoin & Swartz 2010)가 실제로 NHL 관행을 바꿨다는 점, 축구의 ASA 2018 분석이 "역습 위험이 2배면 이득, 4배면 손해"까지 계산했지만 **그 배수를 아무도 재지 않았다**는 점. → "우리는 그걸 잽니다."
- **이유**: 선행연구를 목록이 아니라 "빈칸이 있다"는 이야기 하나로 전달합니다.

### S4. 왜 아무도 못 했나: 5,902경기 중 60건 (50초)
- **그림** ⚙️: 점 그리드. 작은 회색 점(코너 약 58,000개를 1점 = 100개로 축약)이 화면을 채우고, 빨간 점 60개만 강조. 그 옆에 큰 숫자 "득점 1 · 실점 5".
- **글**: 제목 문장만.
- **말**: "골키퍼가 올라간 코너는 이만큼밖에 없고, 골은 단 하나입니다. 올렸을 때와 안 올렸을 때를 직접 비교하면 아무 결론도 낼 수 없습니다. 그래서 질문을 쪼갰습니다."
- **이유**: 기술적 난점을 숫자 하나로 체감시키고, 다음 장의 아이디어로 자연스럽게 넘어갑니다.

### S5. 아이디어: 드문 사건을 흔한 사건으로 쪼갠다 (80초)
- **그림**: 저울 다이어그램을 단계적으로 쌓습니다(클릭마다 한 블록씩).
  1. 왼쪽 접시 "**골키퍼 1명이 더해지면 골 확률이 얼마나 오르나**" → 근거: 코너 수만 개 + 스냅사진 2,468장
  2. 오른쪽 접시 "**빈 골문이 되면 역습 실점이 몇 배가 되나**" → 근거: 코너 후 역습 수만 건 + 골키퍼가 골문을 비운 슈팅 212개 + 트래킹으로 잰 역습 속도
  3. 받침대 "**남은 시간에 골이 날 확률**" → 근거: 경기 약 5,900개의 득점 시각
  4. 맨 위 "→ 종료 휘슬부터 거꾸로 계산해 **올릴지 말지 판정**"
- **글**: 블록 제목과 표본 수만.
- **말**: "골키퍼가 올라간 장면은 60개뿐이지만, 각 부품은 수천~수만 번씩 일어납니다." 하키 연구도 같은 방식이었다고 한 문장. 실제 사례 60건은 학습이 아니라 **최종 결과가 말이 되는지 점검**하는 데만 쓴다고 덧붙입니다.
- **이유**: 1차안의 분해도와 아키텍처를 한 장으로 합쳤고, 모델 이름 대신 "무엇을 재는가"로 설명합니다.

### S6. 데이터: 그 순간의 스냅사진 (50초)
- **그림** ⚙️: 360 프레임을 피치 위에 그린 그림 1장. 월드컵 2022 덴마크–호주 93분 코너에서 덴마크 골키퍼가 상대 박스 안에 있는 장면. 공격팀 파랑, 수비팀 빨강, 골키퍼는 별 모양으로 강조.
- **글**: 그림 아래 한 줄 표: "StatsBomb 3,961경기 · Wyscout 1,941경기 · 트래킹 27경기 — 모두 공개 데이터, 수집 완료".
- **말**: "이런 스냅사진이 코너 2,468개에 있습니다. 여기서 골키퍼가 어디 있었는지, 박스에 몇 명이 있었는지를 직접 셉니다." 데이터 정제 이야기는 하지 않습니다(질문 대비 부록).
- **이유**: 소스 목록보다 데이터가 실제로 어떻게 생겼는지 한 장면을 보여 주는 것이 훨씬 잘 전달됩니다. 이 그림이 이후 "선수 한 명 더 넣어 보기"를 이해하는 기반이 됩니다.

### S7. 이미 보이는 것, 그리고 아직 안 보이는 것 (70초)
- **그림** ⚙️: 차트 2개를 좌우로.
  - 왼쪽(빨강, **확실한 결과**): 코너 후 60초 안 실점률. 전체 0.69% vs 85분 이후 지고 있을 때 1.81%, 95% 신뢰구간 표시(겹치지 않음).
  - 오른쪽(파랑, **불확실한 결과**): 박스 안 공격 인원 4~7명별 코너 기대득점, 오차막대 포함. 점들이 오차막대 안에서 겹쳐 보이는 그대로.
- **글**: 왼쪽 "막판엔 역습 실점 위험 약 2.6배", 오른쪽 "1명 더 넣은 효과? 단순 비교로는 구분 불가".
- **말**: 왼쪽은 이미 데이터로 확인된 사실입니다. 오른쪽은 "박스에 몇 명 넣느냐는 상황마다 달라서(지고 있을수록 많이 넣고, 상대도 더 많이 막음) 단순 평균으로는 효과가 묻힌다. 그래서 장면 전체를 읽는 신경망으로 '같은 장면에 한 명만 더 넣어 보기'를 하고, 통계적 인과 추정으로 그 답을 교차 검증한다."
- **이유**: 정직하게 "모르는 것"을 보여 주는 것이 모델이 왜 필요한지에 대한 가장 강한 설득입니다. 1차안의 "효과는 작다" 메시지는 데이터가 뒷받침하지 않으므로 고쳤습니다.

### S8. 손으로 풀어 보기: 마지막 코너라면? (80초)
- **그림**: 큰 숫자로 된 간단한 계산판(애니메이션으로 한 줄씩).
  - 상황: 리그 경기, 1골 뒤진 채 마지막 코너
  - 올렸다가 골 → 무승부: **+1점**
  - 올렸다가 실점 → 어차피 패배: **0점 손해**
  - → "잃을 게 없다 → 무조건 올린다"
  - 그 아래 물음표: "그럼 종료 5분 전이라면? 실점하면 **동점 기회 자체가 사라진다**"
- **글**: 위 계산판 그대로(숫자와 화살표 위주).
