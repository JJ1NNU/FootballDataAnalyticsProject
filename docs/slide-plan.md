# 발표 슬라이드 구성안: 골키퍼를 올릴 것인가

> 기반 문서: [`project-proposal.md`](./project-proposal.md) · 수치 출처: [`data/derived/summary.json`](../data/derived/summary.json)
> 가정: 기획 발표 10~12분, 슬라이드 14장(본문 13 + 부록). 장당 평균 45~50초.

## 전체 원칙

| 전달 수단 | 무엇을 담나 | 기준 |
|---|---|---|
| **그림·사진·영상** | 장면, 데이터 규모, 수치 비교, 모델 흐름 | 청중이 **3초 안에** 이해해야 하는 것. 숫자 비교는 무조건 차트 |
| **슬라이드 글** | 질문, 핵심 결론 한 줄, 꼭 기억해야 할 숫자 2~3개 | 한 장에 **제목 + 한 줄 메시지 + 키워드 3개 이내**. 문장형 불릿 금지 |
| **말(발표자 설명)** | 이유, 맥락, 방법의 디테일, 한계의 근거 | 슬라이드에 쓰면 읽히기만 하고 이해되지 않는 것. 예: "왜 직접 비교가 안 되나" |

- 모든 슬라이드 제목은 **주장형 문장**으로 씁니다. 예: "데이터" 대신 "골키퍼가 실제로 올라간 경기는 5,902경기 중 60건뿐".
- 색 규칙: 공격 이득 = 파랑, 실점 위험 = 빨강, 불확실성 = 회색 음영. 모든 차트에서 같게 씁니다.
- ⚙️ 표시는 **이미 수집한 데이터로 지금 바로 그릴 수 있는 그림**입니다(`data/derived/`).

## 슬라이드별 구성

### 1. 표지 (20초)
- **그림**: 알리송 헤더 순간 정지 화면(배경, 어둡게 처리). 오른쪽 아래에 조지아 빈 골문 실점 장면을 작게 겹쳐 대비.
- **글**: 제목 "골키퍼를 올릴 것인가", 부제 "경기 막판 코너킥 골키퍼 공격 가담의 효용과 최적 정책", 팀명·날짜.
- **말**: "오늘은 축구 감독들이 매주 하는데 아무도 데이터로 답하지 않은 결정 하나를 다룹니다."

### 2. 장면으로 시작: 같은 선택, 정반대 결과 (60초)
- **그림·영상**: 화면을 반으로 나눠 영상 두 개를 각 10~15초 재생.
  - 왼쪽: 알리송 95분 헤더 결승골([NBC Sports](https://www.youtube.com/watch?v=CFXkwCtEzDQ))
  - 오른쪽: 조지아 골키퍼 가담 → 90+7분 빈 골문 실점([FOX Soccer](https://www.youtube.com/watch?v=f7JinPLrBOg))
  - 재생이 불안정할 때를 대비해 정지 화면 2장도 준비합니다.
- **글**: 영상 아래에 "+2점(무→승)" / "1골 차 → 2골 차" 두 줄만.
- **말**: 상황 설명(1-1 동점 95분, 1-2 열세 추가시간). "한 번 성공하면 승점 2점, 실패하면 그대로 패배에 실점 추가. 이 두 결과의 확률을 비교하는 것이 이 연구입니다."

### 3. 연구 질문: 언제 올려야 하나 (40초)
- **그림**: 가운데 저울 아이콘. 왼쪽 접시 "공격수 +1 → 득점 확률 ↑"(파랑), 오른쪽 접시 "빈 골문 → 역습 실점 ↑"(빨강), 받침대에 "남은 시간 · 점수차 · 리그/토너먼트".
- **글**: 연구 질문 4개를 키워드로만. "① 득점 이득 ② 실점 위험 ③ 언제 올려야 하나 ④ 감독들은 합리적인가".
- **말**: 각 질문을 한 문장씩 풀어 설명. 결과물이 "가담 권장 지도"라는 점을 미리 예고합니다.

### 4. 왜 아무도 답하지 못했나: 선행연구 (50초)
- **그림**: 가로 타임라인 1개.
  - 하키: Beaudoin & Swartz 2010 → Asness & Brown 2018 → NHL 감독들이 실제로 더 일찍 골리를 빼기 시작.
  - 축구: ASA 2018(블로그) → **공백** → 이 프로젝트.
- **글**: "하키: 감독들은 너무 늦게, 너무 드물게 뺀다" / "축구: 핵심 수치를 하키에서 빌려 가정".
- **말**: ASA 분석의 손익분기 논리(역습 위험 2배면 이득, 4배면 손해)를 소개하고, "그 2배·4배를 아무도 측정하지 않았다"는 점을 강조합니다. 학술 논문을 찾지 못했다는 조사 과정은 말로만 짧게.

### 5. 핵심 난점: 골키퍼가 실제로 올라간 경기는 5,902경기 중 60건 (50초)
- **그림** ⚙️: 큰 숫자 대비 인포그래픽. "5,902경기 · 58,115 코너" 바탕 위에 점 60개만 강조 표시(와플 차트 또는 점 그리드). 그 옆에 "득점 1건 / 60초 내 실점 5건".
- **글**: 제목 문장 + "직접 비교 불가".
- **말**: 60건으로 "올렸을 때 vs 안 올렸을 때"를 비교하면 왜 아무 결론도 못 내는지(득점 1건으로는 비율 추정 불가). "그래서 문제를 쪼갰습니다"로 다음 장 연결.

### 6. 데이터: 공개 데이터 전부 긁어모았다 (50초)
- **그림** ⚙️: 데이터 소스 5개를 가로 막대(코너 수, 로그 스케일)로 표시. StatsBomb 38,799 / 그중 360 2,468 / Wyscout 19,316 / 트래킹 156(Sportec 47 + SkillCorner 109) / 골키퍼 가담 후보 60. 각 막대 옆에 로고와 작은 아이콘("선수 위치", "역습 속도").
- **보조 그림**: 360 프레임 한 장을 피치 위에 그린 예시(덴마크 93분 코너, 골키퍼가 박스 안에 있는 장면) ⚙️.
- **글**: 막대 라벨만. "모두 공개 데이터, 수집 완료".
- **말**: 각 데이터가 무엇에 쓰이는지 한 문장씩. 360이 "골키퍼가 어디 있었는지"를 직접 보여 주는 유일한 공개 데이터라는 점. 공급사별 좌표 오류를 정제한 과정은 질문이 나오면 답합니다.

### 7. 이미 보이는 것: 기초 분석 결과 (60초)
- **그림** ⚙️: 작은 차트 3개를 한 줄로.
  1. 코너 후 60초 내 실점률 막대: 전체 0.69% vs 85분 이후 열세 1.81% (오차막대 = 95% CI). 빨강.
  2. 박스 안 공격 인원(4~7명)별 점유당 xG 선그래프: 0.045 → 0.053. 파랑, 기울기가 완만함을 강조.
  3. 수비 골키퍼의 골문 거리별 "실제 득점 / xG" 막대: 1.05 → 1.64. "xG가 빈 골문을 과소평가".
- **글**: 각 차트 위에 한 줄 결론. "막판엔 역습 위험 2.6배", "1명 추가 효과는 작다", "빈 골문은 xG의 1.5배".
- **말**: 세 결과가 각각 저울의 어느 쪽 무게인지 연결. 아직 기술통계일 뿐 인과가 아니라는 단서를 말로 붙입니다.

### 8. 방법 ①: 드문 사건을 흔한 사건으로 쪼갠다 (60초)
- **그림**: 분해 다이어그램. 맨 위 "골키퍼 가담 효과(n = 60)"에서 화살표 4개로 아래 상자 4개로 분기. 각 상자에 표본 수를 크게 표시:
  - (a) 공격수 +1 효과 — 코너 2,200~58,000
  - (b) 역습 발생 확률 — 코너 58,000
  - (c) 빈 골문 득점률 — 슈팅 100,000
  - (d) 막판 득점 강도 — 경기 5,900
- **글**: 상자 라벨과 숫자만.
- **말**: 극소량 데이터 전략 5가지 중 핵심 셋(분해, 자연 변동 준실험, 대리 상황 차용)을 이 그림 위에서 설명. "하키 연구도 같은 방식으로 시뮬레이터를 만들었다."

### 9. 방법 ②: 모델링 아키텍처 (70초)
- **그림**: 기획서의 흐름도를 다이어그램으로. 왼쪽 세 모델(코너 공격 GNN / 역습·빈 골문 / 경기 상태) → 가운데 의사결정 모델 → 오른쪽 결과물(권장 지도). 코너 공격 모델 상자 안에 "그래프에 노드 1개 추가" 미니 그림(피치 위 점들 + 점 하나 반짝).
- **글**: 상자 이름과 출력값 기호만(Δp, r, λ(t), ΔV).
- **말**: 모델별 역할을 한 문장씩. 특히 "반사실 질의 = 같은 코너에 선수 한 명만 더한다면?"을 그림으로 짚어 줍니다. GATv2, GAM, 포아송 같은 모델명은 말로만 언급(슬라이드에는 쓰지 않음).

### 10. 방법 ③: 검증 장치와 참고한 선행연구 (45초)
- **그림**: 왼쪽에 "GNN 반사실 Δ"와 "DML 자연 변동 추정"이 겹치는 두 신뢰구간 그림(가상 예시, 회색 표시). 오른쪽에 참고 연구 카드 4장(TacticAI, Beaudoin & Swartz, ASA 2018, VAEP) 썸네일.
- **글**: "두 방법이 일치하면 채택, 어긋나면 보수적인 쪽" / 카드 제목.
- **말**: TacticAI의 코너 GNN과 배치 조정 아이디어를 공개 데이터로 축소 재현한다는 점. 실제 사례 60건은 학습이 아니라 검증과 감독 행동 비교에만 쓴다는 점(선택 편향 때문).

### 11. 기대 결과: 골키퍼 가담 권장 지도 (60초)
- **그림**: 히트맵 목업. x축 남은 시간(80~95+분), y축 점수차(−2, −1, 0). 색 = 가담이 이득일 확률(파랑 = 이득, 빨강 = 손해, 경계 부근 회색 음영). 리그/토너먼트 두 패널. "예상 결과(가설)" 워터마크를 명시합니다.
- **글**: "1골 열세 · 마지막 2~3분 → 가담" / "동점 · 토너먼트 → 유지" 두 줄.
- **말**: 가설의 근거(이득은 작고, 위험은 크지만, 질 경기에서는 잃을 것이 없음). 기대 효과 세 가지(코칭 의사결정 근거, ASA 가정의 실측 대체, 다른 드문 전술 결정으로 확장).

### 12. 얼마나 믿을 수 있나: 한계와 신뢰도 (60초)
- **그림**: 신뢰도 막대 하나를 세 구간으로. "경계에서 먼 상황 = 높음", "경계 근처 = ±1~2분", "효과 크기 = 넓은 구간". 아래에 한계 6개를 아이콘 6개로(🔮 반사실 검증 불가, 📉 효과 ≈ 잡음, 🔁 대리 상황, 🤺 상대 반응, ⚙️ 모형 가정, 🌍 대표성).
- **글**: 아이콘 라벨(2~3단어)만. "방향은 신뢰, 경계는 ±1~2분".
- **말**: 각 한계의 근거 수치를 말로. 실점률 CI 1.28~2.56%, 빈 골문 표본 212개, 하키 연구 간 최적 시점 차이(약 3분 vs 6분). "그래서 점추정이 아니라 확률 지도로 보고합니다."

### 13. 일정 (35초)
- **그림**: 7주 간트 차트. 0주차(완료)는 체크 표시, 11/23 중간 점검과 12/21 최종 발표에 마일스톤 다이아몬드.
- **글**: 주차별 작업 키워드(골드셋 → 1차 모델 → GNN → 역습 위험 → 의사결정 → 행동 비교 → 발표).
- **말**: "데이터 수집은 이미 끝났다"는 점을 강조하고, 중간 점검의 대안 계획(GNN과 DML이 어긋나면 DML 채택)을 한 문장으로.

### 14. 마무리 (20초)
- **그림**: 2번 슬라이드의 두 장면 정지 화면을 다시 띄우고 가운데 물음표.
- **글**: "95분, 1골 뒤진 코너킥. 골키퍼를 올리시겠습니까?"
- **말**: 청중에게 직접 질문하고 손을 들게 한 뒤 Q&A로 전환. 최종 발표에서는 같은 질문에 모델의 답을 보여 주겠다고 예고합니다.

### 부록 (질문 대비, 발표하지 않음)
- A1. 데이터 정제 이슈: Wyscout 좌표 반전 이벤트, 360 골키퍼 라벨 오류, Sportec 결측 좌표.
- A2. 골키퍼 가담 탐지 경로 4가지와 각각의 편향 표.
- A3. 후보 60건 목록(대회, 분, 점수차, 결과).
- A4. ASA 2018의 계산 원문 재현(코너 득점 0.028 × 10% × 2점 vs 역습 비용).
- A5. 모델별 세부 사양(GATv2 구조, 증강, 그룹 교차검증, 부트스트랩 횟수).
