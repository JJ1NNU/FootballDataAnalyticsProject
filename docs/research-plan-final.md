# 경기 막판 코너킥 상황 골키퍼 공격 가담의 효용 분석 — 최종 연구 기획

인공지능학과 안진우 · 최종 발표 2026-12-21

이 문서는 세션에서 논의해 확정한 연구 기획을 한곳에 정리한 것이다. 이전 문서(`gk-corner-experiment-plan.md`, `project-proposal.md`)와 다른 내용이 있으면 이 문서를 따른다. 특히 2절의 데이터 수치는 자가검증 후 수정한 값이다.

## 1. 연구 주제

### 1-1. 질문
경기 막판에 지고 있거나 비기고 있는 팀이 코너킥을 얻었을 때, 골키퍼를 상대 박스로 올리는 것이 이득인가. 이득이라면 **남은 시간이 몇 분일 때부터** 이득인가.

### 1-2. 세부 목표
1. **득점 확률 증가량 정량화**: 골키퍼 1명이 추가될 때 코너킥 득점 기대값의 변화
2. **실점 확률 증가량 정량화**: 골문을 비운 상태에서 역습 실점 확률의 변화
3. **지시 판정**: 남은 시간 · 점수차 · 대회 형태(리그/토너먼트)를 고려해 골키퍼 가담의 이득 여부 계산

### 1-3. 선행연구와 공백
- 축구에서 이 질문을 데이터 모델로 다룬 학술 연구는 찾지 못했다.
- 유일한 정량 분석은 American Soccer Analysis 블로그(Young, 2018)다. 골키퍼가 언제 골문을 비웠는지 데이터가 없어서 역습 위험 배수를 2배, 4배로 **가정**했다.
- 아이스하키의 골리 빼기 연구(Beaudoin & Swartz, 2010)가 같은 구조의 질문을 시뮬레이터로 다뤘다. 방법론의 전례로 참고한다(발표 슬라이드에서는 제외, 질문 대비용).

### 1-4. 사례 영상
- 알리송 95분 헤더 결승골, 웨스트브롬 1-2 리버풀 (2021.05.16): https://www.youtube.com/watch?v=CFXkwCtEzDQ
- 마마르다슈빌리 97분 코너킥 가담 후 실점, 튀르키예 3-1 조지아 (2024.06.19): https://www.youtube.com/watch?v=f7JinPLrBOg

### 2-3. 골키퍼 가담 탐지 방법과 검증 결과
탐지 경로 세 가지 중 하나라도 해당하고, 80분 이후 동점 또는 열세인 코너를 후보로 삼았다.

| 경로 | 기준 | 검증 결과 |
|---|---|---|
| ① 스냅사진 | 코너 순간 공격팀 골키퍼 x > 90 | 정상 |
| ② 이벤트 | 코너 공격 중 공격팀 골키퍼가 x > 80에서 공을 건드림 | StatsBomb 정상. Wyscout 1건 좌표 반전 오탐(러시아–스페인 연장) |
| ③ 역습 슈팅 | 코너 후 60초 안 상대 슈팅 순간 골키퍼가 골문에서 20m 이상 | **기준 오류.** 코너 때 골키퍼의 평소 위치가 골문에서 중앙값 37m라서 평소 위치까지 잡힘. 14건 중 8건 오탐 |

추가 사항:
- 가담 50건은 **탐지된 것만의 하한**이다. 이벤트 경로는 골키퍼가 공을 건드려야 잡히는데, 스냅사진으로 확인된 가담 12건 중 공을 건드린 경우는 4건(약 1/3)이었다.
- 영상 확인이 필요한 2건: 풀럼–아스널(2003/04, 골키퍼 48m), 인테르 여자팀 84분 동점.
- 탐지된 가담 사례는 **학습에 쓰지 않는다.** 경로 ③은 실점한 경우에만 잡히는 편향이 있다. 가담 사례는 방향 점검과 검증용으로만 쓴다.

### 2-4. 실점 집계 기준
- 기존 기준: 코너 후 60초 안, 같은 하프 안의 상대 득점. 역습 연결 여부는 확인하지 않음.
- 검증 결과, 전체 코너의 60초 내 실점 266건 중 90건은 코너 직후 첫 상대 공격에서 나온 골이 아니었다.
- **변경 기준:** 코너 → 클리어 → 재개 없이 이어진 역습 실점만 집계한다.

| 구분 | 60초 기준 | 코너 직후 첫 상대 공격 기준 |
|---|---|---|
| 전체 코너 | 0.69% | 0.64% |
| 85분 이후 열세 | 1.81% | **1.46%** (95% 신뢰구간 0.99~2.15%) |

막판 열세일 때 실점률이 2배 이상이라는 결론은 두 기준 모두에서 유지된다.

## 3. 연구 방법: 반사실 추정

### 3-1. 왜 직접 비교하지 않는가
가담 50건에서 득점 1, 실점 3이다. 득점률 기저값이 약 3%일 때 n=50이면 표준오차가 약 2.4%p로, 효과 자체보다 크다. 가담 사례와 비가담 사례를 직접 비교하는 방법은 쓸 수 없다.

### 3-2. 방법 개요
> 골키퍼가 올라가지 않은 일반 코너킥 · 슈팅 · 경기 데이터로 부품 모델을 학습하고, 골키퍼가 올라간 상황을 가정해 넣은 뒤 차이를 계산한다. (Counterfactual Reasoning)

- 한 코너에 대해 "골키퍼가 올라간 결과"와 "안 올라간 결과" 중 하나만 관측된다. 관측되지 않은 쪽을 모델로 추정한다.
- 엄밀하게는 3단계 반사실(관측된 결과까지 조건으로 반영)보다 **장면 조건부 개입 효과 추정**에 가깝다. 구조는 인과 머신러닝의 S-learner다. 발표에서는 "반사실 추정(가상 개입)"으로 부르고, 질문이 나오면 이렇게 답한다.

### 3-3. 모델 구조

```
① 코너킥 득점 모델 ─┐
② 역습 실점 모델   ─┼─→ ④ 판정 모델 ─→ 골키퍼 가담 권장 지도
③ 남은 시간 모델   ─┘
```

| 모델 | 반사실 여부 | 학습 방식 |
|---|---|---|
| ① 코너킥 득점 | 예 (공격수 1명 추가) | 데이터로 학습 |
| ② 역습 실점 | 일부 (골문이 빈 상태를 다른 상황에서 차용) | 데이터 학습 + 가정 기반 계산 |
| ③ 남은 시간 | 아님 (골 하나를 승점으로 바꾸는 계산) | 데이터로 학습 |
| ④ 판정 | 정책 비교 (올린다 / 안 올린다) | 역방향 귀납 + 부트스트랩 |

## 4. 모델 상세

### 4-1. ① 코너킥 득점 모델

| 항목 | 내용 |
|---|---|
| 입력 | 코너 순간 스냅사진의 선수 위치를 그래프로 표현 (노드 = 선수, 엣지 = 같은 팀/상대 팀) |
| 모델 | GATv2 그래프 신경망 + 좌우 반전 증강 (TacticAI 구조를 축소 재현) |
| 출력 | 코너 공격의 득점 기대값 (xG) |
| 반사실 질의 | 실제 장면에 공격수 노드 1개를 추가해 다시 예측. 증가량 = f(장면 + 1명) − f(장면) |
| 노드 위치 | 한 곳으로 고정하지 않음. 여러 위치(니어포스트, 페널티 스팟 등)의 평균과 범위로 보고 |
| 기준선 | 박스 인원 수를 넣은 LightGBM / 로지스틱 회귀. GNN이 보정(calibration)에서 이길 때만 주 모델로 사용 |
| 검증 | 경기 단위 교차검증, DML 교차 확인 (4-5절) |

### 4-2. ② 역습 실점 모델
세 부품의 곱으로 계산한다.

```
P(실점 | 가담) = P(역습 슈팅 도달) × P(골키퍼 복귀 실패) × P(빈 골문 득점)
               + P(역습 슈팅 도달) × P(골키퍼 복귀) × P(일반 슈팅 득점)
```

| 부품 | 방식 | 데이터 | 비고 |
|---|---|---|---|
| ②-a 역습 슈팅 도달 | 로지스틱 회귀 / LightGBM + 슈팅까지 시간 분포 | StatsBomb 코너 직후 첫 상대 공격 (`counter_shot`, `counter_secs`), 스냅사진의 뒤에 남은 수비 인원 | 빈 골문을 노린 장거리 슈팅 증가분은 일반 데이터로 못 잡음 → 골키퍼가 멀리 있던 슈팅 212개와 가담 사례로 따로 추정하고 범위로 처리 |
| ②-b 골키퍼 복귀 | 계산: P(슈팅까지 시간 < 복귀 거리 ÷ 골키퍼 속도) | 거리: 스냅사진 가담 12건 (약 100~114m). 속도: Sportec·SkillCorner | 가정 기반. 거리·속도를 범위로 두고 민감도 보고 |
| ②-c 빈 골문 득점 | 로지스틱 GAM: 골 ~ f(슈팅 거리) + f(각도) + f(골키퍼–골문 거리) | 슈팅 약 10만 개 전체로 학습, 골키퍼 20m 이상 슈팅 212개로 끝부분 확인 | 골키퍼 20~30m: 실제 골 / xG = 1.64 (n=174), 30m 이상: 1.48 (n=38) |

출력:
- **역습 위험 배수 r** = 가담 시 실점 확률 ÷ 정상 시 실점 확률. ASA(2018)의 가정값 2배, 4배와 비교한다.
- 부트스트랩 신뢰구간

검증:
- 정상 위치로 계산한 실점률이 실제 막판 열세 기저율(1.46%)을 재현하는지
- 가담 50건의 실측 실점 3건(6%, 95% 신뢰구간 약 2~16%)과 대조 (방향 점검용)

추천하지 않는 대안과 이유:
- 시퀀스 딥러닝으로 실점 직접 예측: 학습 데이터에 가담이 거의 없어 가담 상황으로 넘겨 쓸 수 없음
- 트래킹 기반 역습 시뮬레이션: 트래킹 코너 156개뿐이고 가담 장면 없음. ②-b 확인용으로만 사용
- 마르코프 체인(xT 방식): "골키퍼 없음" 상태의 전이 확률을 추정할 데이터가 없음

### 4-3. ③ 남은 시간 득점 모델 (골 하나의 가치 모델)

| 항목 | 내용 |
|---|---|
| 모델 | 시간 비균질 포아송 회귀 |
| 데이터 단위 | 경기 × 팀 × 분 (약 110만 행) |
| 입력 | 분, 점수차, 퇴장 수 차이, 홈 여부, 팀 전력 |
| 출력 | 남은 시간 동안 양 팀의 분당 득점 확률 |
| 용도 | 득점·실점 1개가 최종 승점(리그) 또는 진출 확률(토너먼트)을 얼마나 바꾸는지 계산 → "몇 분부터"에 답함 |
| 검증 | 보류한 시즌으로 실제 경기 결과 예측 정확도 확인 |

### 4-4. ④ 판정 모델

```
득점 확률 증가량 × 골키퍼 올려서 득점했을 때의 승점 증가량
        vs
실점 확률 증가량 × 골키퍼 올려서 실점했을 때의 승점 손해량
```

- 상태: (남은 시간, 점수차). 경기 종료 시점부터 거꾸로 계산하는 **역방향 귀납**으로 각 상태의 가치 V(t, 점수차)를 구한다. 그래서 "지금 실점하면 남은 시간의 만회 기회까지 사라진다"는 점이 자동으로 반영된다.
- 리그: 기대 승점. 토너먼트: 진출 확률 (연장전 반영, 승부차기는 50%로 가정).
- 부트스트랩으로 ①②③을 다시 추정해, 각 상태에서 **가담이 이득일 확률**을 계산한다.
- 계산 예시 (85분, 임의 값): 이득 0.0062 vs 손해 0.0025 → 가담 이득.

### 4-5. DML 교차 확인 (① 검증)

**목적:** GNN의 "공격수 1명 추가 시 xG 증가량"을, 실제로 박스 인원이 달랐던 코너들의 비교로 다시 추정해 맞춰 본다.

**필요한 이유:**
- 노드 추가는 학습 범위 밖의 입력이다.
- S-learner는 약한 처치 효과를 0 쪽으로 줄여 추정하는 경향이 있다.
- 박스 인원은 상황(분, 점수차, 팀 전력)에 따라 정해지므로, 단순 비교는 교란된다.

**절차:**
1. LightGBM으로 xG(Y)를 교란 변수(X)로 예측하고 잔차 Ỹ를 구한다.
2. LightGBM으로 박스 인원(D)을 X로 예측하고 잔차 D̃를 구한다.
3. Ỹ를 D̃에 회귀해 기울기 θ(공격수 1명당 xG 변화)와 95% 신뢰구간을 구한다.
4. 1~2단계는 경기 단위 5묶음 교차 적합(cross-fitting)으로 계산한다.

| 항목 | 설정 |
|---|---|
| 데이터 | 스냅사진이 있는 롱 코너 |
| Y | `poss_xg` (보조: 득점 여부) |
| D | `att_in_box` (4~7명) |
| X | 분, 점수차, 퇴장 수 차이, 홈 여부, 팀 전력, 코너 방향, 인스윙/아웃스윙, 대회, 남녀, 팀별 과거 세트피스 xG |
| X에서 제외 | `def_in_box` (공격 인원을 보고 상대가 반응해 정해지는 값) |
| 도구 | `DoubleML`의 `DoubleMLPLR` 또는 `econml`의 `LinearDML` |

**판정:**

| 결과 | 해석 |
|---|---|
| GNN 평균이 DML 신뢰구간 안 | 일치. GNN 결과 사용 |
| GNN 평균이 구간 밖 | GNN 오류 가능성. 원인 분석 후 DML 값을 기준으로 사용 |
| DML 구간이 0 포함 | 효과가 데이터로 구분되지 않을 만큼 작음. 손익분기 분석으로 넘어감 |

**한계:** 측정 안 된 교란(선수 키, 세트피스 전술의 질), "골키퍼 = 필드 공격수 1명" 문제는 해결하지 못한다. 기본형은 인원과 무관하게 효과가 일정하다고 가정한다(필요하면 범주형 처치로 확장). 4~7명 범위 안에서만 해석한다.

## 5. 신뢰도 확보 장치

| 장치 | 대상 | 내용 |
|---|---|---|
| DML 교차 확인 | ① | 4-5절 |
| 기준선 비교 | ① | GNN vs LightGBM / 로지스틱 |
| 손익분기 분석 | ①, ② | "득점 증가량이 최소 얼마여야 이득인가", "역습 위험 배수 r이 몇을 넘으면 손해인가" |
| 민감도 분석 | "골키퍼 = 공격수 1명" 가정 | 골키퍼를 공격수 0.5~1.0명분으로 두고 결론 변화 확인 |
| 민감도 분석 | ②-b | 골키퍼 복귀 거리·속도를 범위로 |
| 트래킹 대조 | ②-b | 실제 골키퍼 이동 속도, 역습 시간 |
| 기저율 재현 | ② | 막판 열세 실점률 1.46% |
| 표본 외 검증 | ③ | 보류 시즌 |
| 실제 사례 대조 | 전체 | 가담 50건 (득점 1, 실점 3). 방향 점검용 |
| 부트스트랩 | ④ | 이득 확률과 신뢰구간 |

경계에서 먼 상황(예: 70분 2골 차, 95분 1골 차)은 높은 신뢰로 판정할 수 있고, 경계 근처는 1~2분 정도의 불확실성이 남을 것으로 예상한다.

## 7. 최종 산출물

**골키퍼 가담 권장 지도**
- 행: 점수차 (0, −1, −2)
- 열: 남은 경기 시간 (10′, 8′, 6′, 4′, 2′, 0′+)
- 칸: 골키퍼를 올리는 쪽이 이득일 확률
- 리그와 토너먼트를 각각 계산한다.
- 실제 가담 사례와 가담하지 않은 막판 코너를 지도 위에 표시해, 감독들의 선택이 권장보다 보수적인지 확인한다.

부산물:
- ASA(2018)가 가정한 역습 위험 배수의 실측 추정값
- 빈 골문 득점 곡선 (골키퍼–골문 거리별)

## 9. 관련 연구 메모: TacticAI (Wang 외, 2024)

| 항목 | TacticAI | 본 연구 |
|---|---|---|
| 데이터 | 프리미어리그 트래킹 코너 7,176개 (위치, 속도, 키, 몸무게) | 스냅사진 코너 2,468개 (위치만) |
| 인코더 | GATv2 4층 + D2 대칭 그룹 합성곱 | GATv2 + 좌우 반전 증강 |
| 예측 | 첫 수신자 (Top-3 0.782), 슈팅 (F1 0.64, 수신자 조건부 2단계 분해) | 코너 공격 xG |
| 가상 개입 | 조건부 VAE로 한 팀의 위치·속도 재생성 (슈팅 조건을 바꿔 입력) | 공격수 노드 직접 추가 |
| 개입 효과 | 수비 조정 시 슈팅 확률 0.75 → 0.69, 공격 조정 시 0.18 → 0.31 | 계획 |
| 검증 | 분류기 현실성 검사 (F1 0.53), 전문가 5명 평가 (90% 유익) | DML, 실제 사례 대조 |

가져오는 것: 인코더 구조, "바꾼 장면을 예측 모델에 다시 넣어 차이를 보는" 평가 방식, 현실성 검사 아이디어(노드를 넣은 장면을 실제 가담 스냅사진 12건과 비교).

선택 사항: TacticAI처럼 "골키퍼가 첫 수신자가 될 확률"을 따로 보면, 골키퍼 추가 효과가 직접 득점 기회에서 오는지 수비 분산에서 오는지 구분할 수 있다.

가져오지 않는 것: 생성 모델(CVAE). 본 연구는 "어떤 배치가 좋은가"가 아니라 "1명을 더하면 얼마나 달라지는가"를 재기 때문이다.
