# P2 OBSO 구현·설정 확정 — S06~S08 (체크포인트 12-03)

### S06 · OBSO CPU 기준 구현 (4-1·4-2·4-4절) → E05
1. **담당:** obso-engineer
2. **할 일:** `obso.py`를 numpy FP64로 구현한다.
   - PPCF: Spearman MAP 값, 운동 모델은 LaurieOnTracking, 적분 0.04 s.
   - 골키퍼 λ는 박스 안에서만 ×3으로 한다.
   - 오프사이드 라인은 반사실 골키퍼를 포함해 계산한다.
   - T는 N(B, 23.9) · C^1.04로 두고 정규화한다.
   - S는 S04의 A(r)와 w를 써서 계산하고, p_shot′에 b를 반영한다.
   - 깊이 격자 D, d_obs, 21명 도달 시간 캐시를 구현한다. `run_counterfactual.py`는 4-5절 지표를 계산한다.
3. **얻고자 하는 것:** 프레임 하나에 대한 곡선 O(d)와 분해값(Σ T·C, 평균 w), 4-5절 지표. 그리고 FP64 **정답지**.
4. **목적:** GPU 구현과 모든 검증의 기준이 되는 참조 구현을 확정한다.
5. **유의사항:**
   - 오프사이드(최솟값 3개, 0.2 m 여유), 박스 경계, 반쪽 칸 104.5, 동점 기준 10⁻⁶, d_top 정의를 조항 그대로 구현한다.
   - 대표 장면 몇 개로 C·S·O 지도를 그려 눈으로도 점검한다.
   - w 정규화, 오프사이드, A(r) 거리는 pytest로 확인한다.
- **완료 기준:** pytest와 감사 통과, `/code-review` 지적 사항 처리, E05 작성(구현 명세와 단위 검증).

### S07 · C 검증과 주 설정 확정 (5-3) → E06
1. **담당:** obso-engineer. 지표 계산은 같은 에이전트가 맡는다.
2. **할 일:**
   - 뒷공간 패스를 추출한다. 끝 지점은 다음 이벤트 프레임의 공 위치로 둔다.
   - 결과 라벨은 다음 이벤트의 팀으로 정한다. TacklingGame은 `raw_event`의 승자 팀을 쓴다.
   - 제외 규칙을 적용한다.
   - 주 설정과 LaurieOnTracking 세트 두 가지로 C(끝 지점)를 계산하고, 건수, AUC, 로그손실, 보정 곡선을 비교한다.
3. **얻고자 하는 것:** 두 세트의 성능표와, 로그손실이 작은 세트로 정해지는 **주 통제 파라미터**.
4. **목적:** 이 연구의 공간 통제 C가 실제 뒷공간 경합 결과를 설명하는지 검증하고, 출처가 다른 파라미터 조합 중 하나를 데이터로 고른다.
5. **유의사항:**
   - 4-7의 3번 항목(GENERIC 이름, 승자 팀 속성 이름)을 먼저 실측해 확인한다. 예상과 다르면 멈춘다.
   - 실제 골키퍼 위치와 속도를 쓴다. 반사실 위치를 쓰지 않는다.
   - 선택 규칙은 로그손실 하나뿐이다. AUC가 반대 방향을 가리켜도 규칙을 바꾸지 않고, 그 사실을 레포트에 적는다.
- **완료 기준:** 주 설정을 확정해 `config.py`에 반영함, 감사 통과, E06 작성.

### S08 · b 선택 (4-4절) → E07
1. **담당:** stat-modeler
2. **할 일:** IDSSE 분석 프레임에서 결과 변수를 만든다. 공 가진 선수가 같은 시퀀스 안에서 3초 안에 SHOT을 했는지 여부다. 모형은 P = logit⁻¹(a + logit p_shot′(B))이고, b ∈ {0, 0.25, 0.5}마다 절편 a를 함께 추정한다. 이항 로그우도를 비교한다.
3. **얻고자 하는 것:** b별 로그우도, 사건 수, w ≥ 0.5 프레임 수, 그리고 주 설정 b. 점검이 불가능하면 0.25로 두고 "점검 불가"로 표시한다.
4. **목적:** 골문이 비었을 때 슈팅 시도가 늘어나는 정도를 데이터로 고른다. 결론의 강건성 판정은 b 세 값 모두를 쓴다.
5. **유의사항:**
   - w는 관측 골키퍼 위치 기준으로, τ = 0으로 계산한다. 30개 기준은 두 조건에 각각 적용한다.
   - 사건 수가 적어 로그우도 차이가 작아도 규칙대로 고른다. 차이의 크기는 레포트에 적는다.
- **완료 기준:** 주 설정 b를 확정함, 감사 통과, E07 작성. **12-03 체크포인트를 점검한다.**
